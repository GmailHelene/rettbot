## 🔒 Sikkerhet

### 5-Lags Kryptering

Din data krypteres **5 ganger** før lagring:

```
1. AES-256-GCM (med din masterkey)
2. ChaCha20-Poly1305 (tilfeldig nøkkel)
3. AES-256-GCM (shard-nøkkel)
4. AES-256-GCM (paranoid lag 1)
5. AES-256-GCM (paranoid lag 2)

= Uknekka fram til år 2500+
```

### Zero-Knowledge Arkitektur

- ✅ All kryptering skjer i din nettleser
- ✅ Serveren ser ALDRI dine data i klartekst
- ✅ Selv om serveren hackes, er dataene uleselige
- ✅ Selv om din enhet beslaglegges, er dataene beskyttet

### Anti-Forensics

- ✅ Ingen digitale fotspor
- ✅ Sikker sletting av RAM
- ✅ Sikker sletting av disk
- ✅ Umulig å gjenopprette data

### Duress Mode (Nød-Modus)

Sett opp et **alternativt passord** som:
- Viser kun lokke-data (falske saker)
- Sletter ALT ekte data i bakgrunnen
- Beskytter deg hvis du tvinges til å logge inn

### Distributed Backup

Data deles i **5 fragmenter** og lagres på:
- IPFS (desentralisert)
- ProtonDrive (zero-knowledge cloud)
- Tor hidden service (.onion)
- Lokalt (kryptert)

**Trenger bare 3 av 5 fragmenter for gjenoppretting**
